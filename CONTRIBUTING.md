# Contributing to Team Tools Guide

How to contribute to this repository:
1. Assign an issue to yourself and create a branch from main.
2. Make your edits and commit them with a clear message (short and written in the imperative mood, for example: "Fix typo", not "changes").
3. Push your branch and open a Pull Request referencing the issue (for example, Closes #2).

**Golden Rule:** Nobody commits directly to main. All changes must go through a branch and a Pull Request.
